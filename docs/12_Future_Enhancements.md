# 12 - Future Enhancements

## Roadmap

### Version 1.1

-   Access review reminders
-   Email notifications
-   Bulk user import
-   CSV export
-   Advanced dashboard filters

### Version 2.0

-   Live API usage monitoring
-   API key metadata inventory
-   Token expiry reminders
-   Scheduled access reviews
-   Approval SLAs
-   Notification center

### Version 2.5

-   Slack / Microsoft Teams approvals
-   SSO (Azure AD / Okta)
-   LDAP synchronization
-   Department auto-provisioning

### Version 3.0

-   API Gateway integration
-   Compliance dashboards
-   Risk scoring
-   Anomaly detection
-   SIEM integration
-   Usage forecasting

## Out of Scope for v1

-   Store production secrets
-   Proxy API traffic
-   Build an API gateway
-   Replace enterprise IAM

## Technical Debt Backlog

-   Repository pattern (optional)
-   Test coverage \>80%
-   Docker Compose
-   CI/CD pipeline
-   Redis caching (if required)
-   Background jobs

## Product Vision

Become a central governance portal for API ownership, approval
workflows, and employee lifecycle management while integrating with
enterprise identity systems.
