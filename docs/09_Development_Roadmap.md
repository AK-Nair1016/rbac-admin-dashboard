# 09 - Development Roadmap

## Objective

Deliver the platform incrementally while keeping every milestone
deployable.

## Milestone 1 - Foundation

-   Refactor backend (service layer, validation, responses)
-   Preserve existing JWT authentication
-   Preserve RBAC
-   Refactor frontend layout Definition of Done:
-   Existing functionality unchanged
-   Clean architecture

## Milestone 2 - Organization

Features: - Departments - Teams - Employee Profile enhancements -
Dashboard navigation updates

## Milestone 3 - API Catalog

Features: - CRUD APIs (metadata only) - API ownership - Environment &
version - Search & pagination

## Milestone 4 - Access Governance

Features: - Access Requests - Approval workflow - Grant / Reject -
Revoke / Extend - Expiry dates

## Milestone 5 - Dashboard

KPIs - Active Employees - APIs Managed - Active Access - Pending
Requests - Expiring Access Charts - Access by Team - Request Trend -
Access Status - Top Requested APIs

## Milestone 6 - Employee Lifecycle

Onboarding - Assign defaults - Audit creation

Offboarding - Disable account - Revoke access - Close requests - Archive
history

## GitHub Epics

1.  Backend Refactor
2.  Frontend Refresh
3.  API Catalog
4.  Access Requests
5.  Approval Workflow
6.  Dashboard
7.  Audit
8.  Employee Lifecycle

## Definition of Done

-   Unit tested
-   Validation implemented
-   Audit event generated
-   UI responsive
-   Documentation updated
